# Group Chat Room

A simple terminal-based group chat application made using Python and JSON.

This project allows users to:
- Log in with a username
- Join existing chat rooms
- Create new chat rooms
- Send messages
- View messages with date and time
- Switch users and rooms

The chat data is stored inside a `data.json` file.

## Features

- Multiple chat rooms
- Persistent message storage using JSON
- Timestamp for every message
- Room creation support
- Simple command-line interface

## Technologies Used

- Python
- JSON
- Datetime module
